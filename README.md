Nombre: fitwoman

es una aplicación móvil diseñada para ayudar a las mujeres a mantener un estilo de vida saludable. Permite registrar comidas, rutinas de ejercicio y fotos de progreso para seguir la evolución del bienestar físico y emocional.


idea del modelo CRUD: 

CREATE: registrar comidas, entrenamientos o hábitos diarios. 
ej.("desayuno Lunes: Avena con frutas", "Rutina de piernas (Glúteo y femoral, cardio u otro tipo de entrenamiento))

READ: mostrar una lista con todos los registros por categorías o fecha. 
ej.(Ver comidas del día o rutinas semanales) 

UPDATE: Editar los datos de una comida o entrenamiento 
ej.(cambiar la rutina, duración o las calorías de la comida) 

DELETE: Borrar un registro antiguo (un año hacía atrás) 
ej.(Eliminar una comida o rutina que no se quiera guardar) 

Extras para el proyecto: 
Búsqueda personalizada (filtrar por fecha, tipo, comida o entrenamiento)

imágenes/cámara (Tomar fotos de progresos mensuales o de comidas, eñ uso de galería para comparar fotos de un "antes y un después"


Mockups principales 
-Login de la usuaria 
- el plan de entrenamiento
-  ejecución del ejercio
-  calendario con entrenamientos completados o en progreso
-  fotos registras de un progreso mensual
-  comidas recomendadas por la app
-  contador de calorias
